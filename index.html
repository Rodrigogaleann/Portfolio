Sobre mí

Lógica primero, código después

Estudio la Tecnicatura en Programación en la UTN y trabajo con un enfoque pragmático: entender bien el problema, modelar los datos con cuidado y recién entonces escribir código que otra persona pueda mantener.

Me siento cómodo en el backend con C# y ASP.NET, en bases de datos relacionales (consultas complejas, triggers, políticas RLS) y en el frontend con HTML, CSS y JavaScript sin frameworks.

  • UTNTecnicatura en Programación
  • 4proyectos web desarrollados
  • C#y SQL Server como base

Preguntas frecuentes

¿Qué tipo de trabajos hacés?

Sitios y landings en HTML, CSS y JavaScript, sistemas web con C# y ASP.NET MVC, y apps con base de datos en SQL Server o Supabase.

¿Con qué formación trabajás?

Curso la Tecnicatura en Programación en la UTN. Mi base está en lógica de programación, bases de datos relacionales y arquitectura de software.

¿Cómo se publica un proyecto?

Los sitios estáticos se despliegan en Netlify, conectados a GitHub, así cada cambio se publica automáticamente.
